Agent 查询配方 v0.5.1+

端到端改代码时优先用高层工具；底层 flag 仅在需要精确控制时使用。所有结果都是已索引边，不是完整运行时图。

1. 优先命令（MCP / CLI）

爆炸半径 blast_radius

agentgraph blast-radius <symbol> [--depth 3] [--include-macro]
MCP: blast_radius
  • 自动选窗：subset_ok → window=sound，否则 window=default
  • 不会盲目开 --recall
  • 返回 promise_tier / recommendation / stale
  • --include-macro 仅当 sidecar 存在且非 stale/嵌套

谁调用了它 who_calls

agentgraph who-calls <symbol> [--noisy] [--limit 50]
MCP: who_calls
  • 默认 noisy=false：callers 与 implementors 分栏；fmt/clone 等高频名 demote
  • --noisy：合并旧式嘈杂列表
  • Exact 调用在低 --limit 下不会被 implementor 挤掉（R31）

HTML 关系图 graph

agentgraph graph <symbol> [--depth N] [--direction impact|callers|both] [--sound] [--out path.html]
MCP: graph  →  { html, window, subset_ok, promise_tier, recommendation, node_count, edge_count, sha256 }
  • Agent 不必 shell 到 CLI：MCP graph 直接返回自包含 HTML 字符串（离线、无 CDN）
  • 默认 path=null（纯字符串）；提供 out 时才写盘，且必须在 workspace root jail 内
  • sound=true：仅当 subset_ok=true 才标 window=sound；违例时 window=disabled + honest disabled HTML + recommendation
  • auto_window=true：复用 blast_radius 选窗（subset_ok → sound，否则 default，绝不盲 recall）
  • sound 与 with_macro 互斥（fail-closed）
  • 字段含 html_bytes / sha256（可缓存/比对）与 note（非完整运行时图）

2. sound 关闸时怎么问（怕漏）

agentgraph subset --workspace workspace.json
# 看 sound_candidates[] + recommendation

agentgraph blast-radius X --workspace workspace.json
# window=default 时 recommendation 已含：sound_candidates[] + 示例
# impact X --sound --workspace-root <eligible_root>（脏 union 永不 window=sound）

agentgraph blast-radius X --workspace workspace.json --workspace-root ./packages/repository
# 或
agentgraph impact X --sound --workspace-root <eligible_root>
  • 全仓有 unsafe/parse_error → 全局 sound disabled 是诚实行为
  • 用 sound_candidates 里 sound_eligible=true 的 crate/root 做 scoped sound
  • blast_radius 的 recommendation / example_command 给出下一步合法命令；无合格 root 时诚实说明并引导 default + review implementors
  • 不要用全局 --recall 代替 scoped sound（勿作默认）

4. 机器可读字段

字段含义
edge_rolecall | implementor | registration | dynamic · 勿改名
windowsound | default | disabled（blast_radius / MCP graph）· 勿改名
subset_ok选中 store/root 的 S 闸门 · 勿改名
html / sha256MCP graph 自包含 HTML + 内容摘要 · 勿改名
promise_tierast_modeled | lexical_v1 | mixed | disabled · 勿改名
sound_candidates还可做 scoped sound 的 root/path（eligible first）· 勿改名
by_root / by_top_dirscoped-sound 分桶（多根 / 单根顶层目录）· 勿改名
sound_eligible该 scope 是否 0 S violations · 勿改名
example_commanddefault window 时的合法下一步，如 impact <sym> --sound --workspace-root <id> · 勿改名
baseline_stalewatch/增量后 diff 基线未刷新 · 勿改名
sidecar_stale / sidecar_exists宏旁路状态（status 即可读，不建文件）· 勿改名
recommendation一句话建议（sound/默认/宏/stale/下一步合法命令）· 勿改名
note恒为 not a complete runtime graph · 勿改名
root_id / root_pathworkspace 多根归属 · 勿改名

5. 禁止误读

  • 没有「零漏报 / 生态 sound / 宏完整」
  • --sound 与 --with-macro 互斥（CLI + MCP graph 同）
  • MCP graph 在 subset_ok=false 时不得把 window 标成 sound
  • workspace union 的 sound = 最弱 root
  • L1 / implementor 是候选，不是运行时完备调用图
